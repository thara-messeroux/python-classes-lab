# Python Tic-Tac-Toe (Py-Pac-Poe)

A terminal-based Tic-Tac-Toe game built to practice Object-Oriented Programming (OOP) principles in Python.

## Purpose
The goal of this project is to transition JavaScript OOP concepts (classes, state, and methods) into idiomatic Python syntax by managing game states and data structures within a centralized `Game` class.

## Technologies Used
* Python 3
* Git / GitHub

## How to Run
Execute the following command in your terminal:
```bash
python3 exercises.py
